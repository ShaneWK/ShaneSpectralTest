# ShaneSpectralTest

A Python implementation of the spectral test using LLL reduction and spectral score evaluation.

## Overview
This repository contains the core code for Deliverable 1 of my DSoR project. 
It implements the spectral test for linear congruential generators (LCGs) using 
lattice construction, LLL reduction, shortest vector extraction, and spectral 
score computation.

## Contents
Lattice construction for m-dimensional spectral test
LLL reduction (NumPy/SymPy-based implementation)
Shortest vector extraction
Spectral score evaluation
Jupyter notebook demonstrating the full pipeline

## Usage
Run the Jupyter notebook `ShaneSpectralTest.ipynb` to execute the spectral test 
pipeline and compute spectral scores for sample LCG parameters.
